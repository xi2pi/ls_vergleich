# Vergleich von Leitsatzentscheidungen für verschiedene Zeitpunkte

Dieses Repository enthält Quellcode zum Vergleich von Datensätzen gerichtlicher Leitsatzentscheidungen für verschiedene Zeitpunkte.

Die zugrunde liegende Sammlung der Entscheidungen ist unter folgendem Link verfügbar: [https://github.com/xi2pi/ls_sammlung](https://github.com/xi2pi/ls_sammlung)

## Wie es funktioniert

Es wird eine Datei ls_all.xlsx und eine weitere Datei (bspw. ls_all_2025.xlsx) geladen. Es werden die Unterschiede der beiden Dateien spaltenweise gefunden und in einer neuen Datei unterschiede.xlsx gespeichert.
